# Air Quality Index (AQI) Prediction using Machine Learning

## 📌 Project Overview

This project aims to predict the **Air Quality Index (AQI)** using Machine Learning techniques.

The project follows a complete end-to-end Data Science workflow, including:

- Data Collection using Kaggle API
- Data Cleaning
- Data Filtering
- Exploratory Data Analysis (EDA)
- Data Visualization
- Feature Engineering
- Machine Learning Model Training
- Model Evaluation

---

## 🎯 Objectives

- Understand the factors affecting AQI.
- Perform comprehensive exploratory data analysis.
- Build a Linear Regression model for AQI prediction.
- Compare with advanced models in later stages.
- Follow industry-standard project structure and Git workflow.
